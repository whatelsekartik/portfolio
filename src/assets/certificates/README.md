# Certificate wall assets

Copy these files into the repository at `src/assets/certificates/`.
The Achievements gallery discovers image files in this folder automatically at build time.
Add a matching entry in `src/data/certificates.ts` to set the title, issuer, category,
outcome and ISO sort date. Files without metadata appear under Other and sort last when
newest-first is selected. Use the event end date for multi-day events.

- `certificate1.webp` — GitHub Hands-On Workshop
- `certificate2.webp` — WCC Launchpad 30
- `certificate3.webp` — Promptify / Anveshan 3.0
- `certificate4.webp` — PRAXIS 2026 / Storyverse
- `certificate5.webp` — CodeSprint 2026

- `certificate7.webp` — Pixel Perfect
